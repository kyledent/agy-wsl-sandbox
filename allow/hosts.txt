# "host" matches that host only; "*.example.com" matches its subdomains, not example.com itself; "host:8443" allows
# that port as well. Every address a host resolves to must be public, or the proxy refuses it anyway.

# Hosts are named one by one on purpose. "*.googleapis.com" would include storage.googleapis.com, where anyone can
# upload to a bucket of their own, so it would be a way to send your workspace out.
